Back Row Pocket Games

Quick browser games to play when the lecture drags on. Each game is a single HTML file, so there is nothing to install and nothing to sign in to.

Games
Game	File	Play
Tic-Tac-Toe	tic-tac-toe.html	Two players or vs computer
Connect Four	connect-four.html	Two players or vs computer
Snake	snake.html	Arrow keys, WASD, buttons or swipe
Breakout	breakout.html	Mouse, touch or arrow keys
Memory Match	memory-match.html	4×4 or 4×6 board
Chess	chess.html	Two players or vs computer
2048	2048.html	Arrow keys, WASD, buttons or swipe
How to play

Open any .html file in a web browser. You can also play online once GitHub Pages is on:

https://kaif-1906.github.io/back-row-pocket-games/

Each game is at its own address, for example:

https://kaif-1906.github.io/back-row-pocket-games/snake.html

Running locally
Download this repository or the zip file.
Unzip it.
Double-click any .html file.

No internet connection is needed after download.

Notes
Works on phones, tablets and computers.
Chess does not include en passant or the repetition and fifty-move draw rules.
Scores are not saved after you close the page.
